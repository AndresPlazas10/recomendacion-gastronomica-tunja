# Experimentos

Scripts y notebooks para:

1. Generar el dataset sintético reproducible (semilla versionada).
2. Construir el split temporal (entrenamiento/validación/prueba).
3. Comparar baseline de popularidad vs contenido vs híbrido.
4. Registrar resultados (MLflow si aporta valor).

Reglas:

- No usar datos personales reales sin anonimizar.
- Reportar separadamente resultados sintéticos (técnicos) y reales (validación).
- Versionar semilla, dataset y configuración de cada corrida.

Referencia: documentación de planificación del proyecto (`docs/README.md`).
